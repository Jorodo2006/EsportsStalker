# MMA (UFC, PFL y WOW) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir MMA como quinta app de Sharpex (UFC, PFL y WOW): combates, luchadores, previsión de victoria, cuotas de Winamax/Betway y apuestas con resolución automática.

**Architecture:** Nuevo servicio `mma` (puerto 4007, esquema `mma`) con el mismo patrón que `football`/`tennis`: ESPN para UFC y PFL, lectura de wowmma.com para WOW, modelo Elo propio con backtest. El comparador de cuotas, el cupón y las apuestas se amplían con `sport: 'mma'`. La interfaz añade la app `mma` (acento rojo apagado) con vistas Combates y Luchadores.

**Tech Stack:** Node (CommonJS, `node:http`, `pg`, `node:test`), React 19 + TS + Tailwind 4 + TanStack Query, Playwright (lector), PostgreSQL, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-13-mma-design.md`. Leer también `AGENTS.md` (reglas no negociables) y usar `server/services/football/` y `server/services/tennis/` como plantilla.

- Rama `mma`. **Nada de `git commit` ni `git push` sin que Jordi lo pida en ese momento** (AGENTS.md, regla 8): las tareas terminan con `git status`, no con commit. Si Jordi pide commit, mensaje terminado en `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Combate **anulado / sin resultado / empate / cancelado o luchador sustituido**: no debe resolver apuestas ni mostrar probabilidades erróneas (tests en Tasks 3 y 5).
2. **Cartelera vacía de WOW** (evento futuro sin combates) y HTML de WOW cambiado: devuelve lista vacía y aviso, sin romper UFC/PFL (Task 2).
3. **Evento que cruza la medianoche en hora de España** (UFC empieza ~22:00Z y termina de madrugada): el combate sale en el día correcto y no duplicado (Task 1).
4. **Nombres de luchador con acentos, apodos o orden distinto** entre ESPN/WOW y las casas ("Ilia Topuria"/"Topuria I."): el emparejado no debe cruzar luchadores (Task 4).
5. **ESPN caído o 429**: se sirve la caché y no hay error 500 (Task 1).
